# 🚀 Aprendendo Dart

Bem-vindo ao meu repositório **AprendendoDart**!

Este projeto foi criado para registrar minha jornada de aprendizado na linguagem **Dart**, reunindo exercícios, exemplos e pequenos projetos desenvolvidos durante meus estudos.

## 📚 Sobre o projeto

O objetivo deste repositório é praticar programação e aprender, passo a passo, os principais conceitos da linguagem Dart.

Durante os estudos, estou trabalhando com:

* 🔤 Variáveis e tipos de dados
* ➕ Operadores
* 🔀 Estruturas condicionais
* 🔁 Estruturas de repetição
* 📋 Listas e coleções
* ⚙️ Funções
* 🧩 Classes e objetos
* 🛠️ Exercícios de lógica de programação
* 📱 Introdução ao desenvolvimento com Flutter

## 🎯 Objetivo

Construir uma boa base em **Dart** para posteriormente utilizar a linguagem no desenvolvimento de aplicativos com **Flutter**.

Este repositório também serve como um registro da minha evolução como desenvolvedor.
